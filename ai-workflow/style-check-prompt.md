# AI-assisted style check (sample)

A reusable prompt that checks text against a short, fictional style guide.
All content is sample material. It contains nothing from an employer.

## Gemini Gem Prompt

```text
Role: You are a style guide editor and content reviewer.

Goal: Check the text I provide against the style rules below and suggest corrections.

Style rules (sample, fictional):
1. Use active voice.
2. Use title case for headings.
3. Keep sentences under 25 words.
4. Spell out acronyms on first use.
5. Do not use em dashes.

Steps:
1. If I haven't provided text, ask me for it.
2. Review the text against each rule.
3. For each deviation, give the original text, the rule violated, one sentence on why it matters, and a corrected version.
4. Show results in a table with columns: Original | Rule | Why | Suggested fix.
5. If there are no deviations, say the text follows the style rules.
6. Then show the full corrected text.

Constraints:
- Flag only issues covered by the rules. Do not invent new rules.
- If a rule is unclear for a case, say so instead of guessing.
- Tone: professional, precise, and constructive. No emojis.

End by asking whether I have more text to review.
```

## Configuring The Settings Page
The report is generated by the system and sent to admins. SSO config changes login behavior, so test before you save.

## What I observed across runs

- The Gem flagged the heading, the passive sentence, and the acronym. 
- The format of the output varied between runs. Some outputs were a single paragraph, and others were structured lists with sub-items and a warning.
- I changed the heading rule from sentence case to title case after first run. 
- Choices 1 and 2 came from run 2, and choice 3 came from run 3.

## My review of the choices

| 3 | Bulleted list | Fails rule 1 (passive) and rule 4 (SSO not spelled out) | "Connection" instead of "settings" | Breaks two rules: passive voice and an unexplained “SSO”. |

## My final version

> ## Configuring the Settings Page
>
> The system generates the report and sends it to admins. Changing the Single Sign-On (SSO) configuration alters login behavior, so test your settings before you save.

**Why I chose this:** It follows all five rules and uses only facts from my source text. I started from choice 2, removed its opening sentence because the AI invented it, and restored the point that SSO changes affect login behavior.

## What this shows

- The AI followed the rules in most cases, but it added details that were not in my source text. I removed them.
- Outputs varied from run to run, so I read each one before accepting it.
- I made the final decisions.
